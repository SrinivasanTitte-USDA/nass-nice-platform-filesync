# NICE Platform File Sync

## Introduction

The NICE Platform Sync will allow a Source Server to initiate an authenticated connection to a Target Server using HTTPS and synchronize files from a predefined Source Folder to configured folder on the Target Server(s).

## Get the code

Clone the repository using

```shell
git clone https://github.com/SrinivasanTitte-USDA/nass-nice-platform-filesync.git
```

Create a feature branch, for example `YourUserName/CLAS-12345`
